# 🚀 SpaceX Falcon 9 First Stage Landing Prediction
**Data Science Capstone Project**

Este repositorio contiene los Jupyter Notebooks y el código fuente del proyecto final de certificación en Data Science. 

### 📂 Estructura del Proyecto:
1. **Data Collection (API & Web Scraping):** Extracción de datos históricos de lanzamientos.
2. **Data Wrangling & EDA:** Limpieza de datos y análisis exploratorio con SQL y Pandas.
3. **Visual Analytics:** Mapas interactivos con Folium y Dashboards con Plotly Dash.
4. **Machine Learning Prediction:** Entrenamiento de modelos (Logistic Regression, SVM, Decision Tree, KNN) para predecir el éxito del aterrizaje, logrando una precisión del **83.33%**.
